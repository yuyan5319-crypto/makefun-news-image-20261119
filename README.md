A make.fun entry for **news-image-20261119** ("Sum up 19 November's world
news in one image", $250).

`main.ts` (Node 22, standard library only, no network) draws a newspaper
front page of the day's world news pixel by pixel — its own PNG encoder,
rasteriser and 5x7 bitmap typeface — and writes it to `/output/entry.png`
(locally: `MAKEFUN_OUTPUT_DIR=out node main.ts`). The drawing is fully
deterministic: two runs write byte-identical files.
